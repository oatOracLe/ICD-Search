ค้นหารหัส ICD-10

ค้นได้ทั้งรหัสแบบมีหรือไม่มีจุด (E11.9 หรือ E119) ชื่อโรค คำในดัชนี และคำย่อ (DM, HT, C/S, ORIF) · กด / เพื่อไปที่ช่องค้นหา · ใช้ลูกศรขึ้นลงเลือกผลลัพธ์

ขั้นตอนการให้รหัส

  1. อ่านเวชระเบียนให้ครบ ทั้งสรุปการจำหน่าย บันทึกแพทย์ ผลตรวจ และบันทึกการผ่าตัด
  2. หาคำนำ (lead term) ในดัชนีตามตัวอักษร โดยใช้คำที่บอกภาวะ ไม่ใช่ตำแหน่งอวัยวะ
  3. ตามคำขยาย ลงไปจนได้รหัสที่ตรงกับเวชระเบียนที่สุด
  4. ตรวจซ้ำในบัญชีจำแนก (Tabular list) อ่าน Includes, Excludes และหมายเหตุของบท กลุ่ม และรหัส
  5. ให้รหัสครบทุกหลัก และทำตามคำสั่ง เช่น Use additional code หรือ Code also

ห้ามให้รหัสจากดัชนีโดยไม่ตรวจซ้ำในบัญชีจำแนก

ประเภทการวินิจฉัย

1
โรคหลัก (Principal diagnosis) ภาวะที่วินิจฉัยได้เมื่อสิ้นสุดการรักษาว่าเป็นเหตุหลักที่ผู้ป่วยต้องได้รับการรักษาหรือตรวจ
2
โรคร่วม (Comorbidity) มีอยู่ก่อนหรือพร้อมกับโรคหลัก
3
โรคแทรก (Complication) เกิดขึ้นภายหลังระหว่างการรักษา
4
โรคอื่น (Other) ภาวะอื่นที่ไม่เข้า 3 ประเภทแรก
5
สาเหตุภายนอก (External cause) รหัส V01–Y98 ใช้คู่กับรหัสการบาดเจ็บ

ถ้ามีหลายภาวะที่อาจเป็นโรคหลัก ให้เลือกภาวะที่ใช้ทรัพยากรในการรักษามากที่สุด

สัญลักษณ์และป้ายในเว็บนี้

เว็บนี้ใช้ ICD-10 ขององค์การอนามัยโลก (WHO) ฉบับ 2016 เป็นหลัก ชื่อภาษาไทยมาจาก ICD-10-TM 2009

ไม่มีใน WHO
รหัสที่มีใน ICD-10-TM 2009 แต่ WHO ฉบับ 2016 ยกเลิกหรือย้ายไปรหัสอื่น หน้ารายละเอียดจะบอกรหัสที่ใช้แทน
TM
รหัสที่ประเทศไทยเพิ่มเอง (ในเล่มพิมพ์ด้วย #) ไม่มีใน ICD-10 ของ WHO
@
รหัสที่ ICD-10-TM ให้งดใช้ ห้ามใช้ลงรหัส
† / *
รหัสสาเหตุ (†) ต้องใช้คู่กับรหัสอาการแสดง (*) โดยเรียงรหัส † ก่อน
.-
รหัสนี้มีหลักที่ 4 ต้องเลือกหลักที่ 4 ให้ครบ
NOS
ไม่ได้ระบุรายละเอียด (not otherwise specified)
NEC
ไม่ได้จำแนกไว้ที่อื่น (not elsewhere classified)
( )
คำขยายที่มีหรือไม่มีก็ไม่เปลี่ยนรหัส
[ ]
คำพ้อง คำอธิบายเพิ่ม หรือคำย่อ
Excludes
ภาวะที่ต้องไปใช้รหัสอื่นตามที่ระบุ
Use additional code
ใช้รหัสเพิ่มเพื่อให้ข้อมูลครบ เช่น เชื้อก่อโรค
ICD-10

กฎสำคัญในการให้รหัสโรค

  • ใช้รหัสให้ละเอียดที่สุด รหัสที่ยังมีหลักถัดไปเป็นรหัสที่ยังใช้ไม่ได้ ต้องลงถึงหลักสุดท้าย รวมถึงหลักที่ 5 ของ TM
  • รหัสอาการ (บท R) ใช้เมื่อยังไม่มีการวินิจฉัยที่แน่ชัด ไม่ใช้เมื่ออาการนั้นเป็นส่วนหนึ่งของโรคที่วินิจฉัยได้แล้ว
  • บท XV (O00–O99) มาก่อนบทอื่น ภาวะที่เกิดขณะตั้งครรภ์ คลอด หรือหลังคลอด ให้ใช้รหัสบท O เป็นหลัก
  • การบาดเจ็บ ลงรหัส S00–T98 คู่กับสาเหตุภายนอก V01–Y98 และระบุสถานที่เกิดเหตุสำหรับ W00–Y34
  • ระบบ † / * ลงรหัสทั้งคู่ เช่น E11.2† กับ N08.3*
ICD-9-CM

กฎสำคัญในการให้รหัสหัตถการ

  • หัตถการหลัก คือหัตถการที่ทำเพื่อรักษาโรคหลัก หรือหัตถการที่ซับซ้อนที่สุดเมื่อมีหลายรายการ
  • OR procedure (กรอบสีทึบในเล่ม) และ Non-OR ที่มีผลต่อ ThaiDRG (กรอบเส้น) มีผลต่อการจัดกลุ่ม DRG ต้องลงให้ครบ
  • แยกวิธีผ่าตัด แบบเปิดกับผ่านกล้องเป็นรหัสต่างกัน เช่น 47.09 กับ 47.01
  • ทำตาม Code also / Omit code ลงรหัสหัตถการที่ทำร่วมกัน และไม่ลงรหัสส่วนที่เป็นขั้นตอนของหัตถการหลัก

อ้างอิง: ICD-10-TM 2009 Tabular List of Diseases และ WHO ICD-10 Volume 2, ICD-9-CM FY15, คู่มือตรวจสอบเวชระเบียน สปสช. ปี 2562 และ ICD-10-TM Standard Coding Guidelines ตามที่คู่มือ สปสช. อ้างถึง
