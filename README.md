# เว็บค้นรหัส ICD

เว็บสำหรับค้นรหัสโรคและรหัสหัตถการเป็นภาษาไทย ใช้ประกอบงานให้รหัสในโรงพยาบาล

- **ICD-10** อิงบัญชีจำแนกของ WHO ฉบับ 2016 ชื่อภาษาไทยจาก ICD-10-TM 2009
- **ICD-9-CM FY15** พร้อมเครื่องหมาย OR / Non-OR ของ ThaiDRG

**เปิดใช้งาน:** https://oatoracle.github.io/ICD-Search/

> ใช้ประกอบการทำงานเท่านั้น ตรวจรหัสซ้ำกับบัญชีจำแนกฉบับที่หน่วยงานใช้ทุกครั้ง

## ทำอะไรได้บ้าง

| ส่วน | รายละเอียด |
|---|---|
| ค้นหา | ค้นด้วยรหัส (มีหรือไม่มีจุดก็ได้ เช่น E11.9 / E119) ชื่อไทย ชื่ออังกฤษ คำในดัชนี หรือคำย่อ (DM, HT, C/S, ORIF) |
| รายละเอียดรหัส | ลำดับชั้นในบัญชีจำแนก รหัสย่อย หมายเหตุ (รวม / ไม่รวม) แนวทางที่เกี่ยวข้อง เกณฑ์ สปสช. และรายการโปรด |
| ดัชนี ICD-10 | โรคและลักษณะการบาดเจ็บ และสาเหตุภายนอก ไล่ตามตัวอักษรหรือตามหมวด |
| ตาราง ICD-10 | ตารางยาและสารเคมี, ตารางเนื้องอก, สัณฐานวิทยาเนื้องอก (ICD-O), ตารางภาวะแทรกซ้อนของการแท้ง, ตารางอุบัติเหตุการขนส่งทางบก |
| ดัชนี ICD-9-CM | ดัชนีหัตถการ |
| see / see also | กดแล้วไปที่คำนำและคำย่อยที่ระบุ แสดงเฉพาะบรรทัดนั้นกับคำย่อยใต้มัน |
| แนวทาง | ขั้นตอนการให้รหัส กฎสำคัญ และเกณฑ์ตรวจสอบเวชระเบียน สปสช. 2562 |
| หลังบ้าน | เพิ่มหรือแก้รหัส คำย่อ หมายเหตุของหน่วยงาน แถวตาราง และคำในดัชนี โดยไม่แตะข้อมูลหลัก |

ใช้ได้ทั้งบนคอมและมือถือ มีโหมดมืด ใช้งานด้วยคีย์บอร์ดได้ และตรวจการเข้าถึงด้วย axe-core ตามเกณฑ์ WCAG 2.1 AA

## เปิดใช้ในเครื่อง

หน้าเว็บโหลดข้อมูลจากโฟลเดอร์ `web/data` จึงต้องเปิดผ่านเว็บเซิร์ฟเวอร์ ดับเบิลคลิกไฟล์ HTML ตรง ๆ จะโหลดข้อมูลไม่ได้

```bash
git clone https://github.com/oatOracLe/ICD-Search.git
cd ICD-Search/web
python -m http.server 8000
```

แล้วเปิด http://localhost:8000

- **Windows:** ดับเบิลคลิก `start-web.bat` (ต้องมี Python) เบราว์เซอร์จะเปิดให้เอง
- **หลังบ้าน:** http://localhost:8000/index.html#admin

## เผยแพร่ขึ้นเว็บ

ทุกครั้งที่ push การเปลี่ยนแปลงในโฟลเดอร์ `web/` เข้า branch `main` จะมี GitHub Actions (`.github/workflows/pages.yml`) นำโฟลเดอร์ `web/` ขึ้น GitHub Pages ให้เอง ใช้เวลาประมาณ 1 นาที

ถ้าเพิ่งสร้าง repository ใหม่ ให้ตั้งค่าครั้งแรกที่ **Settings → Pages → Source: GitHub Actions**

วิธีเผยแพร่แบบอื่น (Netlify, Cloudflare Pages) ดูใน [`docs/deploy.md`](docs/deploy.md)

## เพิ่มหรือแก้ข้อมูล

ข้อมูลแบ่งเป็น 2 ชั้น เพื่อไม่ให้สิ่งที่แก้เองปนกับข้อมูลจากเอกสารต้นฉบับ

- **ข้อมูลหลัก** (`web/data/icd10`, `web/data/icd9`, `web/data/shared`) สร้างจากเอกสารด้วยสคริปต์ ห้ามแก้มือ
- **ข้อมูลเพิ่มเติม** (`web/data/overlay.json`) แก้ผ่านหลังบ้านเท่านั้น รายการในไฟล์นี้จะทับข้อมูลหลักเมื่อแสดงผล ลบรายการออกเมื่อไรก็กลับไปเป็นข้อมูลหลัก

บน GitHub Pages เว็บเป็นแบบอ่านอย่างเดียว ลิงก์หลังบ้านจะซ่อนอยู่ ขั้นตอนเพิ่มข้อมูล:

1. เปิดเว็บในเครื่อง แล้วไปที่ `#admin`
2. เพิ่มหรือแก้ข้อมูล แล้วกดบันทึกลง `web/data/overlay.json`
3. commit และ push ไฟล์นั้น เว็บจะอัปเดตเอง

รูปแบบข้อมูลแต่ละชนิดดูใน [`docs/backend.md`](docs/backend.md)

## โครงสร้างโฟลเดอร์

```
web/                         เว็บ (ส่วนที่ขึ้น GitHub Pages)
  index.html                 โครงหน้า
  assets/app.js, app.css     ค้นหา ดัชนี ตาราง รายละเอียด และการรวมชั้นข้อมูล
  assets/admin.js, admin.css หลังบ้าน (โหลดเฉพาะหน้า #admin)
  data/manifest.json         รายการไฟล์ข้อมูล แหล่งที่มา และสคริปต์ที่สร้าง
  data/icd10/                codes, keywords, tables, morph (ICD-O), index/
  data/icd9/                 codes, keywords, index/
  data/shared/               คำย่อ แนวทาง เกณฑ์ สปสช.
  data/overlay.json          ข้อมูลเพิ่มเติมจากหลังบ้าน
scripts/who_icd10/           สร้างข้อมูล ICD-10 จาก WHO 2016 + ชื่อไทยจาก TM 2009, ICD-O
scripts/tm_icd9_nhso/        ถอดข้อมูล ICD-10-TM 2009, ICD-9-CM (OCR), ดัชนีหัตถการ, คู่มือ สปสช., คำย่อ
docs/                        คู่มือหลังบ้าน แหล่งข้อมูล การเผยแพร่ และ ER diagram
start-web.bat                เปิดเว็บในเครื่อง (Windows)
```

## สร้างข้อมูลหลักใหม่

สคริปต์ใช้ Python 3 และ PyMuPDF (`pip install pymupdf`) ส่วน OCR ใช้ tesseract ไม่ได้รวมไฟล์ PDF ต้นฉบับไว้ใน repository

พาธในสคริปต์ยังเป็นพาธของเครื่องที่ใช้สร้าง (`/home/claude/...`) ก่อนรันต้องแก้ให้ชี้ไปที่ไฟล์ PDF และโฟลเดอร์ `web/data` ในเครื่องของคุณ

**ICD-10:**
1. `extract_who.py tab` และ `extract_who.py idx`
2. `parse_who_tab.py`, `parse_who_index.py`
3. `build_merged.py`
4. `build_who_index.py`
5. `parse_morph.py`

ชื่อภาษาไทยของ `build_merged.py` มาจากข้อมูล TM 2009 ที่สร้างด้วย `scripts/tm_icd9_nhso`: `extract_tm.py` → `parse_tm.py` → `build_icd10.py`

**ICD-9-CM:**
- `parse_icd9.py` สร้างรายการรหัส
- `parse_index9.py` สร้างดัชนีหัตถการจากผล OCR ทั้งจัดระดับคำย่อยใหม่และทำ see / see also ให้อยู่รูปเดียวกัน

**คำย่อ:** แก้ `scripts/tm_icd9_nhso/abbr.py` แล้วรัน `python abbr.py --check` หรือเพิ่มผ่านหลังบ้านโดยไม่ต้องแก้สคริปต์

รายละเอียดแหล่งข้อมูลและสิ่งที่แก้ไขดูใน [`docs/data-sources.md`](docs/data-sources.md)

## ข้อจำกัดที่ทราบ

- ชื่อภาษาไทย 244 รหัสแปลเพิ่มสำหรับเว็บนี้ ไม่ใช่คำแปลทางการ หน้าเว็บติดหมายเหตุไว้
- ดัชนี ICD-10 ถอดจาก PDF บางคำนำคำย่อยไม่ครบ เช่น Cyst และมีบรรทัดหมายเหตุหลุดเข้ามาบางจุด
- ดัชนีหัตถการ ICD-9-CM มาจาก OCR ของหน้าสแกน บางจุดยังมีคำสะกดเพี้ยนหรือระดับคำย่อยผิด
- ลิงก์ see ไปถึงคำเป้าหมายได้ประมาณ 74% ใน ICD-10 และ 87% ใน ICD-9-CM ที่เหลือจะไปที่คำนำ หรือกรองด้วยข้อความแทน

## ลิขสิทธิ์

- เนื้อหาบัญชีจำแนก ICD-10 เป็นลิขสิทธิ์ขององค์การอนามัยโลก (WHO) ส่วน ICD-10-TM เป็นของกระทรวงสาธารณสุข การเผยแพร่บัญชีจำแนกฉบับเต็มต่อสาธารณะอาจต้องได้รับอนุญาตจากเจ้าของลิขสิทธิ์
- ICD-9-CM เป็นเอกสารของรัฐบาลสหรัฐอเมริกา (NCHS/CMS)
