# นำเว็บขึ้นอินเทอร์เน็ต

เว็บนี้เป็นไฟล์ static ทั้งหมด (HTML, CSS, JS, JSON) ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล อัปโหลดโฟลเดอร์ `web` ขึ้นโฮสต์ฟรีที่ไหนก็ได้

## วิธีที่ง่ายที่สุด: Netlify Drop (ประมาณ 2 นาที)
1. เปิด https://app.netlify.com/drop แล้วสมัครหรือเข้าสู่ระบบ (ใช้บัญชี Google หรือ GitHub ได้)
2. ลากโฟลเดอร์ `web` ทั้งโฟลเดอร์ไปวางในหน้านั้น
3. รอสักครู่จะได้ลิงก์ เช่น `https://ชื่อสุ่ม.netlify.app` เปลี่ยนชื่อได้ใน Site settings → Change site name
4. อัปเดตครั้งต่อไป: หน้า Deploys ของเว็บนั้น ลากโฟลเดอร์ `web` ไปวางใหม่

## ทางเลือกอื่น
- **GitHub Pages** (ใช้อยู่): repository https://github.com/oatOracLe/ICD-Search มี workflow `.github/workflows/pages.yml` เผยแพร่โฟลเดอร์ `web` ทุกครั้งที่ push เข้า `main` ตั้งค่าครั้งแรก: Settings → Pages → Source: GitHub Actions
- **Cloudflare Pages**: Workers & Pages → Create → Pages → Upload assets แล้วเลือกโฟลเดอร์ `web`

## หลังบ้านเมื่ออยู่บนโฮสต์สาธารณะ
- บนโฮสต์สาธารณะ เว็บเป็นแบบอ่านอย่างเดียว ลิงก์หลังบ้านจะซ่อน คนทั่วไปแก้ข้อมูลไม่ได้
- การเพิ่มข้อมูล: เปิดเว็บในเครื่อง (`start-web.bat` → http://localhost:8000/index.html#admin) แก้แล้วบันทึกลง `web/data/overlay.json` จากนั้นอัปโหลดโฟลเดอร์ `web` ขึ้นโฮสต์อีกครั้ง
- ถ้าแก้ผ่านหลังบ้านออนไลน์บน claude.ai ให้ใช้แท็บ "นำเข้า / ส่งออก" ส่งออกเป็น overlay.json แล้ววางทับ `web/data/overlay.json` ก่อนอัปโหลด

## ข้อควรระวังก่อนเปิดสาธารณะ
เนื้อหาบัญชีจำแนก ICD-10 (WHO) และ ICD-10-TM (กระทรวงสาธารณสุข) มีลิขสิทธิ์ การเผยแพร่บัญชีจำแนกฉบับเต็มให้บุคคลทั่วไปอาจต้องได้รับอนุญาตจากเจ้าของลิขสิทธิ์ ถ้าใช้ภายในหน่วยงาน ให้ตั้งรหัสผ่านหรือจำกัดผู้เข้าถึง (Netlify: Site settings → Access control, ต้องใช้แผนที่รองรับ) หรือแชร์ลิงก์ claude.ai เฉพาะคนในหน่วยงานแทน
