# หลังบ้านผู้พัฒนา — คู่มือ

หลังบ้านอยู่ที่ `index.html#admin` ใช้เพิ่มหรือแก้ข้อมูลโดยไม่แตะไฟล์ข้อมูลหลัก

## หลักการ: ข้อมูลแยกเป็นชั้น

| ชั้น | อยู่ที่ | ใครแก้ | หมายเหตุ |
|---|---|---|---|
| ข้อมูลหลัก | `data/icd10/`, `data/icd9/`, `data/shared/` | สคริปต์ใน `scripts/` เท่านั้น | ถอดจากเล่มต้นฉบับ ห้ามแก้มือ สร้างใหม่ได้ทุกเมื่อ |
| ชั้นเพิ่มเติมในเครื่อง | `data/overlay.json` | หลังบ้านโหมดในเครื่อง | เก็บใน git/โฟลเดอร์ได้ |
| ชั้นเพิ่มเติมออนไลน์ | ฐานข้อมูลของเว็บ (collection `overlay`) | หลังบ้านโหมดออนไลน์ | ผู้ใช้ทุกคนเห็นทันที |

ลำดับการรวม: ข้อมูลหลัก → overlay.json → ออนไลน์ (รายการที่ `id` ซ้ำ ใช้ของออนไลน์)
ลบรายการเมื่อไร ข้อมูลกลับเป็นค่าเดิมทันที เพราะข้อมูลหลักไม่เคยถูกเขียนทับ

## สองโหมดของหลังบ้าน

**โหมดในเครื่อง** — เปิดเว็บจากโฟลเดอร์โปรเจกต์ (ดับเบิลคลิก `start-web.bat` แล้วไปที่ http://localhost:8000/index.html#admin)
- ทุกการแก้ไขเก็บชั่วคราวในเบราว์เซอร์ก่อน แล้วกด "บันทึกลงไฟล์ overlay.json"
- Chrome / Edge เขียนทับไฟล์ `web/data/overlay.json` ได้โดยตรง (เลือกไฟล์นั้นครั้งแรก) เบราว์เซอร์อื่นจะดาวน์โหลดไฟล์ให้ไปวางทับเอง

**โหมดออนไลน์** — เปิดเว็บที่เผยแพร่แล้ว ต่อท้ายลิงก์ด้วย `#admin` หรือกด "หลังบ้านผู้พัฒนา" ที่ท้ายหน้า (ลิงก์นี้แสดงเฉพาะผู้มีสิทธิ์)
- บันทึกลงฐานข้อมูลของเว็บ เฉพาะเจ้าของและผู้ที่ได้สิทธิ์ Editor เขียนได้ คนอื่นอ่านอย่างเดียว
- แท็บ "นำเข้า / ส่งออก" ส่งออกรายการทั้งหมดเป็น overlay.json เพื่อเก็บลงโฟลเดอร์โปรเจกต์ และนำเข้าไฟล์จากในเครื่องขึ้นออนไลน์ได้

## ชนิดข้อมูลที่เพิ่มได้ (รูปแบบใน overlay.json)

ทุกรายการมี `id` (ไม่ซ้ำ), `kind`, `updated` (เวลาบันทึก)

| kind | ใช้ทำอะไร | ฟิลด์หลัก |
|---|---|---|
| `code` | เพิ่มรหัสใหม่ แก้ชื่อ เพิ่มหมายเหตุ เปลี่ยนสถานะ หรือซ่อนรหัส | `sys` (icd10/icd9), `c`, `op` (add/edit/hide), `en`, `th`, `da` († หรือ *), `drg` (or/drg), `status` (ok/bad), `parent`, `addNotes` [{`t`, `en`[], `th`[]}], `memo` |
| `abbr` | เพิ่มหรือลบคำย่อ | `sys`, `keys` ("DM\|T2DM"), `op` (add/hide), `en`, `th`, `m` (คำค้นหรือ `@E10-E14`, `@E11`), `top` (รหัสที่ขึ้นก่อน) |
| `note` | หมายเหตุ/ข้อตกลงของหน่วยงาน แสดงในหน้ารหัสและหน้าแนวทาง | `sys` (icd10/icd9/all), `title`, `body`, `codes` (`E11`, `E10-E14`, `J18.9`, `*`) |
| `row` | เพิ่ม แก้ หรือซ่อนแถวในตาราง | `table` (drugs/neoplasm/transport/abortion), `op`, `row` [ระดับ, คำ, ช่อง1..n], `parent` (คำระดับก่อนหน้า), `match` {`term`, `lvl`} สำหรับแก้/ซ่อน, `note` |
| `morph` | เพิ่ม แก้ หรือซ่อนรหัส ICD-O | `op`, `row` {`c` (M8140/3), `g`, `en`, `site`} |
| `idx` | เพิ่มคำในดัชนี | `sys`, `sec` (I/II), `lead`, `sub` [คำขยายตามลำดับชั้น], `c1`, `c2` |

ตัวอย่าง:

```json
{"version": 1, "items": [
  {"id": "note-k3x9", "kind": "note", "sys": "icd10", "title": "ข้อตกลงการลงรหัสเบาหวาน",
   "body": "ระบุภาวะแทรกซ้อนให้ครบ", "codes": ["E10-E14"], "updated": "2026-10-27T14:25:00Z"},
  {"id": "code-icd10-E11.9", "kind": "code", "sys": "icd10", "c": "E11.9", "op": "edit",
   "addNotes": [{"t": "note", "en": [], "th": ["ตรวจ HbA1c ทุกครั้ง"]}], "memo": "ข้อตกลงหน่วยงาน"}
]}
```

## โครงสร้างโค้ด

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าอย่างเดียว |
| `assets/app.css` | หน้าตาเว็บ (สีและธีมมืด/สว่างอยู่ใน `:root`) |
| `assets/app.js` | ค้นหา ดัชนี ตาราง หน้ารายละเอียด และส่วน OVERLAY ที่รวมชั้นข้อมูล (ค้นคำว่า `OVERLAY` ในไฟล์) |
| `assets/admin.js`, `assets/admin.css` | หลังบ้าน โหลดเฉพาะเมื่อเปิด `#admin` และทำงานผ่าน `window.ICDAPP` เท่านั้น |
| `data/manifest.json` | รายการไฟล์ข้อมูลทั้งหมด แหล่งที่มา และสคริปต์ที่สร้าง |

## สร้างข้อมูลหลักใหม่

ดู `README.md` ส่วน "สร้างข้อมูลใหม่" สคริปต์เขียนผลลงโฟลเดอร์ `data/icd10`, `data/icd9`, `data/shared` และไม่แตะ `overlay.json` การสร้างใหม่จึงไม่ลบสิ่งที่เพิ่มผ่านหลังบ้าน
ถ้ารหัสที่เคยแก้ไขหายไปจากข้อมูลหลักรอบใหม่ รายการ `code` แบบ `edit` จะกลายเป็นการเพิ่มรหัสนั้นกลับเข้ามา ให้ตรวจในแท็บ "รหัส ICD"
